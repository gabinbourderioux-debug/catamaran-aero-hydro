1 En résumé

Ce site ne collecte rien : aucun cookie, aucun traqueur, aucun compteur publicitaire, aucun compte à créer, aucune donnée envoyée vers un serveur qui t'identifie. Tu peux tout lire sans rien donner.

2 Ce qui est enregistré sur ton appareil

Deux techniques de « mémoire du navigateur » sont utilisées. Elles restent dans ton navigateur : le site ne peut pas les lire depuis ailleurs, et tu peux les effacer quand tu veux.

Pour tout effacer : réglages du navigateur → « Données de site » / « Stockage local » → supprimer pour ce site. Rien d'autre n'aura été stocké nulle part.

3 Le mot de passe de la zone test

La zone test est protégée par un code personnel. Dans le code source du site, ce code n'apparaît jamais en clair : seul un haché (une empreinte irréversible calculée par l'algorithme djb2) y est stocké. Ton navigateur calcule l'empreinte du code que tu saisis et la compare : le code lui-même ne quitte jamais ton appareil et il n'est pas lisible dans la page.

⚠️ Un hachage côté navigateur protège le code source, pas la porte : c'est une protection de confidentialité (le code n'est connu que de ceux à qui tu l'as donné), pas un coffre-fort. La zone test sert à essayer du code, elle ne contient aucune donnée personnelle.

5 Questions fréquentes

Faut-il accepter des cookies ?

Non. Le site n'utilise pas de cookies du tout — donc pas de bandeau à cliquer. Le bandeau légal n'est obligatoire que si on dépose des cookies ou des traceurs ; ici, seuls de simples réglages (ton thème, tes brouillons) sont mémorisés dans le navigateur, sans suivi de ta navigation.

Qui peut voir mon trafic ?

Le gestionnaire du site voit dans les Statistiques GitHub des chiffres agrégés (pages vues, provenance approximative à l'échelle d'un pays), jamais une identité. Aucun compteur externe n'est installé sur les pages.

Comment poser une question sur cette page ?

Le site est un projet pédagogique signé dans le pied de page : tu peux écrire directement au gestionnaire du dépôt GitHub indiqué en bas.
